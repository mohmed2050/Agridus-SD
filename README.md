# Agridus-SD

تطبيق زراعي سوداني يعمل بدون إنترنت بشكل أساسي، مع ميزات متصلة عند توفر الاتصال.

## المهام المنجزة

### v1.0.0
- [x] **المهمة الأولى**: هيكل التطبيق العام - BottomNavigationBar بستة تبويبات، SQLite محلي، Arabic RTL
- [x] **المهمة الثانية**: قسم المحاصيل - 5 محاصيل سودانية (أبو سبعين، الفول السوداني، القمح، السمسم، البرسيم) مع 11 حقلاً لكل محصول
- [x] **المهمة الثالثة**: قسم الأخبار - RSS من مصادر سودانية، تصفية بكلمات مفتاحية، تخزين مؤقت لـ 20 خبراً
- [x] **المهمة الرابعة**: الطقس والمواقيت - Open-Meteo API + wttr.in كاحتياطي، مواقيت الصلاة (adhan_dart)، إشعارات محلية
- [x] **المهمة الخامسة**: المهام والمؤقتات - To-Do مع إشعارات، تكرار (يومي/أسبوعي)، أرشيف المهام المنجزة

### v2.0.0
- [x] **التقويم الزراعي والتنبيهات**: تقويم موسمي للمحاصيل (زراعة/نمو/حصاد) لكل ولاية، مع تفعيل إشعارات المواعيد
- [x] **حاسبة الأرباح**: حساب التكاليف والأرباح لكل محصول لكل فدان، مقارنة الربحية، مشاركة النتيجة
- [x] **دليل المبيدات والأسمدة**: مبيدات وأسمدة مسجلة في السودان، بحث بالاسم أو الآفة (يشمل مبيدات مكافحة الجراد)
- [x] **أسعار السوق**: أسعار المحاصيل في 5 أسواق سودانية مع التغير ونسبة التغير
- [x] **الإرشاد الزراعي والطوارئ**: مكاتب الإرشاد في 18 ولاية، أرقام الطوارئ، شركات المدخلات الزراعية، دليل إرشادي، تقويم موسمي
- [x] **الوضع الليلي والمزامنة**: وضع ليلي كامل، نسخ احتياطي ومشاركة واستعادة البيانات

## طريقة التشغيل

1. تأكد من تثبيت Flutter SDK (الإصدار 3.44.1 أو أحدث)
2. clone المستودع:
   ```
   git clone https://github.com/mohmed2050/Agridus-SD.git
   cd Agridus-SD
   ```
3. شغّل التطبيق:
   ```
   flutter pub get
   flutter run
   ```

## المنصات المستهدفة

## التقنيات المستخدمة

- Flutter 3.44.1 / Dart 3.12.1
- Provider (إدارة الحالة)
- sqflite (قاعدة بيانات محلية)
- flutter_local_notifications (الإشعارات)
- Open-Meteo API + wttr.in (الطقس)
- adhan_dart (مواقيت الصلاة)
- connectivity_plus (الكشف عن الاتصال)
- share_plus (مشاركة النتائج والبيانات)

## المصادر

- بيانات المحاصيل: وزارة الزراعة السودانية، البنك الزراعي السوداني، هيئة البحوث الزراعية
- الأخبار: وكالة السودان للأنباء (SUNA)، مواقع صحف سودانية
- الطقس: Open-Meteo وwttr.in (مجانيان بدون مفتاح API)
- مواقيت الصلاة: مكتبة adhan_dart بطريقة حساب الهيئة المصرية العامة للمساحة
